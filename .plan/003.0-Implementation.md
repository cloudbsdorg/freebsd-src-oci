## 7. Implementation Details

> **Last reconciled:** 2026-07-21 against `origin/feature/oci-bootstrap`.  
> **On `main`:** `usr.sbin/ocifbsd/` is **not present** until the feature branch is merged.  
> Early drafts of this doc listed a flatter layout (`oci2jail.c` at the top of `ocifbsd/`). The implemented tree uses `src/` for the core runtime and many plan chapters as SUBDIR libraries.

### 7.1 File Layout (actual — `feature/oci-bootstrap`)

```
usr.sbin/ocifbsd/
├── Makefile                 # PROG=ocifbsd + SUBDIR modules; FreeBSD-native first
├── ocifbsd.c                # CLI: create/start/kill/delete/state/list/inspect/run
├── ocifbsd.8
├── README.md
├── OCI-STATUS.md            # Live bootstrap / build status
├── include/
│   └── ocifbsd.h            # Shared types, state enums, constants
├── src/                     # Core runtime (linked into main PROG)
│   ├── container.c          # Lifecycle
│   ├── oci2jail.c           # OCI runtime spec → jailparam
│   ├── state.c              # State under /var/run/ocifbsd
│   ├── hooks.c              # OCI hooks
│   └── utils.c
├── api/                     # REST API library
├── cert/                    # Certificate / ACME / rotation
├── clustering/              # Gossip / Raft scaffolding
├── convert/                 # K8s + Docker Compose conversion (ATF-tested partial)
├── export/                  # Cloud export (AWS/GCP/Azure) scaffolding
├── gc/                      # Garbage collection (delete helpers stubbed)
├── image/                   # ZFS store, pull, push, unpack (LIB)
├── logd/                    # Logging daemon scaffolding
├── metrics/
├── namespace/
├── network/                 # VNET, bridge, CNI (LIB)
├── orchestration/           # Pods/stacks (LIB; stubs.c for container symbols)
├── pam/                     # pam_ocifbsd module
├── security/                # RCTL + MAC (LIB)
├── security-daemon/         # Auth / RBAC scaffolding
└── tools/cross-build/       # Opt-in macOS cross-build helpers

tests/usr.sbin/ocifbsd/
├── Makefile                 # ATF_TESTS_C=parser_test k8s_test
├── parser_test.c            # 22 tests
├── k8s_test.c               # 20 tests
└── ocifbsd_test.c.disabled  # Original core tests — APIs never landed
```

| Path | Type | Description |
|------|------|-------------|
| `usr.sbin/ocifbsd/` | New (feature branch) | Main OCI runtime tree |
| `usr.sbin/ocifbsd/Makefile` | New | Builds PROG + 15 SUBDIRs |
| `usr.sbin/ocifbsd/ocifbsd.c` | New | Main CLI entry |
| `usr.sbin/ocifbsd/include/ocifbsd.h` | New | Common headers |
| `usr.sbin/ocifbsd/src/*` | New | Core runtime sources |
| `usr.sbin/ocifbsd/image/*` | New | Image management LIB |
| `usr.sbin/ocifbsd/network/*` | New | Networking LIB |
| `usr.sbin/ocifbsd/security/*` | New | RCTL / MAC LIB |
| `tests/usr.sbin/ocifbsd/` | New | ATF/kyua tests |
| `usr.sbin/Makefile` | Modified (feature) | Adds `ocifbsd` SUBDIR |
| `release/Makefile.oci` | Existing (main) | OCI base image build (not yet wired to runtime) |

### 7.2 Planned vs actual mapping

| Early plan path | Actual path |
|-----------------|-------------|
| `ocifbsd/oci2jail.c` | `ocifbsd/src/oci2jail.c` |
| `ocifbsd/container.c` | `ocifbsd/src/container.c` |
| `ocifbsd/state.c` | `ocifbsd/src/state.c` |
| `ocifbsd/hooks.c` | `ocifbsd/src/hooks.c` |
| `ocifbsd/utils.c` | `ocifbsd/src/utils.c` |
| `ocifbsd/rctl.c`, `mac.c` | `ocifbsd/security/rctl.c`, `security/mac.c` |
| `ocifbsd/image/*` | `ocifbsd/image/*` (LIB, not PROG) |
| `ocifbsd/network/*` | `ocifbsd/network/*` (LIB) |

Higher-level design chapters (orchestration, clustering, cert, GC, export, PAM, API, logd) each map to a SUBDIR under `usr.sbin/ocifbsd/`. Maturity: see [005.0 §0 and extended modules table](./005.0-Risks-TODO.md).

### 7.3 OCI FreeBSD Extensions

To support FreeBSD-specific features, we extend the OCI runtime config with a `freebsd` section:

```json
{
  "ociVersion": "1.0.2",
  "platform": {
    "os": "freebsd",
    "arch": "amd64"
  },
  "root": {
    "path": "rootfs"
  },
  "process": {
    "args": ["nginx", "-g", "daemon off;"]
  },
  "freebsd": {
    "vnet": true,
    "ip4": ["192.168.1.100/24"],
    "ip6": ["2001:db8::100/64"],
    "mac_label": "biba/high",
    "rctl": {
      "memoryuse": "1G",
      "pcpu": "50",
      "nproc": "100"
    },
    "mounts": [
      {
        "destination": "/dev",
        "type": "devfs",
        "source": "devfs",
        "options": ["ruleset=4"]
      }
    ],
    "network": {
      "type": "bridge",
      "bridge": "bridge0",
      "port_forward": [
        {
          "host_port": 8080,
          "container_port": 80,
          "protocol": "tcp"
        }
      ]
    }
  }
}
```

### 7.4 sysctl Variables

| Variable | Type | Default | Description | Status |
|----------|------|---------|-------------|--------|
| `kern.ocifbsd.enabled` | int | 1 | Global enable/disable for ocifbsd features | Planned (not in kernel yet) |
| `kern.ocifbsd.max_containers` | int | 0 | Maximum containers (0=unlimited) | Planned |
| `kern.ocifbsd.default_vnet` | int | 1 | Default VNET enable for new containers | Planned |
| `kern.ocifbsd.zfs_pool` | string | "zroot" | Default ZFS pool for storage | Planned / userland config preferred |

Bootstrap implementation uses userland state under `/var/run/ocifbsd` and does not require new kernel sysctls.

### 7.5 Build notes

- **Tier-1:** FreeBSD 16 native: `make -C usr.sbin/ocifbsd` (base `/usr/bin/make` is bmake).
- **Dependencies:** base `libjail`, `libutil`, `libzfs`, `libcrypto`, `libmd`, `libpthread`; port `json-c` (`pkg install json-c`). Long-term preference: migrate JSON to `libxo(3)`.
- **Cross-build:** opt-in via `tools/cross-build/` / Makefile `cross-build` targets (macOS/Linux host → FreeBSD amd64 binary).
- **Tests:** `make -C tests/usr.sbin/ocifbsd` then `kyua test -k Kyuafile` on FreeBSD.
