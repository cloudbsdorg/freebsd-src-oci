ocifbsd

FreeBSD-native OCI container runtime — jails as first-class containers.

ocifbsd runs OCI-compliant containers on FreeBSD using native jail(8), VNET, RCTL, and ZFS — no Linux emulation. It ships a full toolchain: image pull/push, pods and orchestration, a Raft-backed cluster daemon, a native ACME certificate client, and log forwarding. The whole tree builds from FreeBSD base with zero ports.

  • Self-containedBuilds with no ports — json-c and libcurl are vendored in-tree; links only FreeBSD base libraries. No GPL anywhere.
  • Native jailsEach container is a jail with VNET isolation, RCTL resource limits, and a ZFS-backed image store.
  • Full Raft clusterLeader election, log replication, persistence, membership changes, and snapshots — via ocifbsd-cluster(8).
  • Native ACMERFC 8555 client with ES256/JWS and HTTP-01 challenges, built on FreeBSD base OpenSSL 3.
